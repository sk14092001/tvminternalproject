# TVM Payroll - Backend (Spring Boot)
## Quick start
1. Ensure MySQL is running and update src/main/resources/application.yml with DB credentials.
2. mvn clean package
3. mvn spring-boot:run
API base: http://localhost:8080/api

requested APIs in a clean and organized way. I’ll include the following functionality:
